# AB Testing Project

    AB Testing data science project with Python.

# Features
    CSV data
    ↓
    Count users in Control & Experiment
    ↓
    Count clicks
    ↓
    Calculate click/conversion rate
    ↓
    Calculate pooled proportion
    ↓
    Calculate standard error
    ↓
    Calculate Z-score
    ↓
    Calculate p-value
    ↓
    Compare p-value with α = 0.05
    ↓
    Reject H0 or Do not reject H0
    ↓
    Draw the hypothesis-testing graph


# Run 
    python3 main.py 


# Installation instructions
    git clone https://github.com/AKP15/AB_Testing_Project.git
